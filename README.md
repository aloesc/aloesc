### About me

I'm Kirill, a developer focused on **Python backend development, data collection, and automation**. I build tools that connect external sources, turn inconsistent responses into structured records, and keep data moving between services.

My projects cover the full path from **collection to delivery**: API integrations, parsers, normalization, database storage, change detection, and synchronization. I also build web interfaces with React and Next.js, and networking tools in Go.

### What I build

- **Data pipelines** — collecting from REST, GraphQL, and web sources; normalizing records and tracking changes.
- **Backend integrations** — connecting services through APIs, with retries, deduplication, and resumable processing.
- **Developer tools** — utilities for exploring HTTP APIs and working with requests.
- **Web applications** — React interfaces backed by practical workflows.
- **Supporting infrastructure** — Docker services, shared databases, and proxy gateways.

I enjoy the parts that make a tool dependable: handling incomplete data, recovering after failures, and making repeated runs predictable.
